Notes

  • AI Search: ARM advertises https://facilities-search.search.windows.net/, which this simulator does not serve; the SDKs use the simulator's ARM-extension path form instead.
  • WAF policies are created and read back, not enforced against traffic by the simulator (no L7 firewall engine).
  • Gateway policy on Azure is APIM policy expressions; Azure has no Cedar-style agent policy engine (AWS AgentCore Gateway and Vertex agentPolicies have one).
  • Runtime is ASSEMBLED: Foundry Agents for the agent definitions plus a LangGraph app in a Container App. Azure has no hosted-agent runtime comparable to AgentCore Runtime.
  • Long-term memory is an APPLICATION PATTERN on Azure Table storage. Azure has no managed long-term memory service (AWS has AgentCore Memory, GCP has Memory Bank).
  • Approval is assembled (Service Bus + Function + Table ledger), not a workflow orchestrator. Service Bus and Cosmos are Vyomi's own cores (Service Bus with a real AMQP 1.0 wire); Table is a real engine (Azurite) only when VYOMI_AZURE_REAL_BACKENDS=1 on a substrate that can run it. This run: real backends ON.
  • Key Vault: KeyClient uses the simulator's https host (not properties.vault_uri, which stays the console path form).
