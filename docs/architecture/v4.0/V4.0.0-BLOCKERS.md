# v4.0.0 blockers

Items that must land before the v4.0.0 release. Add new items at the bottom with the date and who asked.

## 1. One real backend for gateways and event buses, shared by all clouds — owner, 2026-11-12

The GCP API Gateway and Eventarc consoles (and their AWS/Azure siblings) are Vyomi-own control planes today. The owner requires ONE real backend,
used by every cloud, that sits on top of all the applicable cloud resources.

**Gateway data plane** (API Gateway GCP, API Gateway v1/v2 AWS, Azure APIM): a single shared proxy that forwards `https://<gateway host>/<route>` to the
route's backend (`x-google-backend`, HTTP/Lambda/Function integrations) and enforces the config's security (API key, JWT issuer/JWKS) and quota
(metrics, limits, per-operation metricCosts) and throttling. `core/apigatewayv2_gateway.py` already holds a substrate-free handler (CORS, throttling,
JWT, Lambda/HTTP proxy, mocks) behind the shared Caddy gateway — the plan is to generalise that engine and put each cloud's route table on it, not to
build three proxies. Nano reaches it through the tunnel to the local appliance / in-browser engine.

**Event bus** (Eventarc GCP, EventBridge AWS, Event Grid Azure): a single shared bus (retries, dead-lettering, ordering, filtering, delivery to real
Cloud Run / Lambda / Function containers on Pro/Max; tunnel path on Nano). `azure_eventgrid_delivery.py` and `eventbridge_core.py` are the starting points.

Event bus done so far (branch v4/event-bus): shared `core/event_bus_engine.py` (retries/backoff, DLQ, per-key ordering, attempt history); Eventarc delivers through it
(httpEndpoint destination, retryPolicy, deadLetterTopic, console attempt history); EventBridge and Event Grid use it with inline (sync) retries.

Declared limits to retire: `gcp.apigateway.apis-configs-gateways`, `gcp.run.eventarc-job`, `gcp.eventarc.triggers`.

Done so far: OpenAPI security (`securityDefinitions`/`security`) and quota (`x-google-management` metrics/limits, `x-google-quota`) sections are
validated at config creation (`core/gcp_apigateway_core.py`); enforcement needs the data plane above.

Acceptance: a request through each cloud's gateway reaches its backend and is refused without a valid key/JWT or over quota; a real event reaches a
running container with retries; on Nano, the offline appliance and Mesh. Round-trip suite `gcp-v4-roundtrip.mjs` stays green.
