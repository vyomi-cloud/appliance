# v4.0.0 known issues (beta launch)

Status of this file: v4.0.0 ships as a beta on 2026-11-12. Everything below is known, accepted for the beta, and queued to be worked on right after the cut.
Each session adds ITS OWN section (AWS, Azure, portal/Nano, tunnel/Mesh). Keep entries short: what happens, where it shows, workaround, owner, test or file to start from.
Format: `ID | impact | what | workaround | where to start`. Impact = S1 (data loss / wrong answer), S2 (feature does not work), S3 (cosmetic / limit).

## GCP + shared gateway / event-bus (session: gcp-night)

What IS verified for the v4.0.0 blocker "one real backend for gateways and event buses": GCP API Gateway, AWS API Gateway v1/v2 and Azure APIM forward to a real
backend with API key / JWT / quota / throttle enforcement on Nano (real Chromium), the offline Docker stack, and Mesh (`gcp-gateway-eventbus-real.mjs` 52/52 on Mesh
with `PUBLIC_URL`). Eventarc retries, backoff and dead-lettering are verified on all three. The items below are what is NOT closed.
