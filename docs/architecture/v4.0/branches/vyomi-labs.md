# Branch v4/vyomi-labs

**Vyomi Labs**: a hands-on course that builds the 13-layer enterprise "Facilities agent", once per cloud (AWS, Google Cloud, Azure) with that cloud's native services. Opened from the bottom-drawer "Vyomi Labs" item of the v4 Nano consoles (`wasm/vyomi-appbar.js`). Tagged Pro / Max.

## Architecture
- **Source of truth for the text**: `vyomilabs/content/build_courses.py` (+ `explain.py`, `narrative.py`, `setup_steps.py`) -> `wasm/labs/data/<cloud>.json`. Diagrams: `build_diagrams.py` -> `wasm/labs/img/*.svg`.
- **UI**: `wasm/labs/{index.html,labs.js,labs.css}`, loaded in an iframe inside the console dialog. Pages: course catalogue (plan ribbon and Mesh disclaimer), course view (tiles, Start here first), "Start here" lesson (problem, simplest design, why enterprises go beyond functional scope, 13 questions, resulting architecture), and one scrolling lesson per chapter with a sticky, scroll-spied "On this page" menu: problem, why, layer design (analogy, how it works, goals, prerequisites, connected chapters), then build, create, connect, validate and clean up.
- **Deploy**: a lean button in the chapter title. It deploys the chapter's code as written: in the browser runner where possible (AWS only), otherwise inside a Mesh (`/mesh/labs/deploy/<cloud>/<layer>`), starting and joining a Mesh through `window.parent.VyomiMesh` when none is live. Validate embeds the live API reference (read-only operations, Try it).
- **The course project**: `courses/<course-slug>/<cloud>/NN-<layer>/` (code exactly as shown and deployed, plus a README per layer), generated by `vyomilabs/content/build_project.py`; `run_all.sh` assembles the flat workspace the layers import from. The in-page Monaco editor (`wasm/labs/project/<cloud>.json`, textarea fallback offline) opens it, with zip download. Guideline: every course and its Python project lives under `courses/`. `scripts/sync_course_repo.sh` can mirror a course folder to a standalone repository.
- **Models**: lab code discovers the models this simulator hosts (Nano in-browser or the Mesh pool); no vendor model names.

## Decisions
- Course content is cloud-neutral story-first (Priya, a night technician); cloud-specific detail lives in the hands-on sections.
- No quiz questions (removed on request). Pro / Max tag is display only; the Mesh is where the plan is enforced.
- Editor, not GitHub, for "open the full code" (the standalone mirror repo exists but is empty).

## Verified here
- All three clouds render; Start here, catalogue, course view, chapter, editor (open, edit, reset, zip) and the Labs dialog header exercised in headless Chrome. Deploy-through-Mesh exercised against a stub Mesh API only.
- Course code was run with `vyomilabs.labrun` against an in-process simulator.
