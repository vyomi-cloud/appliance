## Reference slice (tests/conformance/test_ai_approvals.py, real boto3)
`Record`(conditional ledger put) -> `Classify`(Lambda) -> low: `AutoApprove` / medium-high: SNS `approver-inbox` publish.waitForTaskToken (3 s timeout in the test; delivered to an SQS inbox) -> approver `SendTaskSuccess`/`SendTaskFailure` -> `Approved` ledger update -> `Execute` -> `Validate` -> `Completed`, or `Compensate` -> `COMPENSATED` + Fail. Rejected / Expired paths update the ledger. Retry with the same idempotency key short-circuits to `Duplicate`.
