Object bytes are also written to MinIO so external S3 tools can read them; the mirror is best-effort and skipped (logged once) when MinIO is unreachable, in which case the inline bytes in state still serve S3. | **inhouse**: Python S3 core in Pyodide, in-memory ObjectStore, IndexedDB snapshot (nano_persist). Browser memory and storage limits apply (not measured here). | Requests are not authenticated: SigV4 is read for routing but never verified, and bucket policies/ACLs are stored but not evaluated for authorization.; Default encryption headers (x-amz-server-side-encryption, KMS key id) are returned, but objects are not encrypted at rest.; Lifecycle, Intelligent-Tiering and Inventory run lazily on read/list rather than on a background schedule.; Replication is synchronous and stays inside the simulator account.; Public Access Block and Object Ownership are enforced only for new ACL/policy writes; existing grants are not retroactively revoked.; Static website hosting, Transfer Acceleration and Requester Pays are wire-level emulations on Vyomi's own host (no real website/accelerate endpoints, no billing payer).; Storage Lens, Access Analyzer for S3, Marketplace for S3 and metadata tables are computed from the simulator's own contents and catalog, not from AWS telemetry. | S3 durability and multi-AZ replication of stored data; AWS billing, request-payer charges and S3 storage-class pricing; Real S3 Express One Zone latency and zonal placement; Real website, CloudFront or Transfer Acceleration edge endpoints |

| **Amazon SNS** (`sns`)<br>Vyomi implements SNS in its own core (core/sns_core.py) on the native Query/XML wire with real fan-out into SQS queues sharing the same messaging store. | SNS Query protocol + XML (2010-03-31); boto3 / aws-cli / SDKs with only the endpoint changed | **inhouse**: Vyomi SNS core (Python), core/sns_delivery.py delivery worker, SQLite kernel state store.
