# Vyomi v2.5.0 — Parity Close-out

**Goal:** close the parity gaps identified in `docs/PARITY-GAPS.md` — starting with the
backing-tech ("cheap tech") gaps that gate a clean real-backend cutover of the v2.4.0
unified ingress, then operation depth and cross-cloud symmetry.

**Principles (unchanged from v2.4.0):** additive + Pro/Max-only for backed stores (never
vendored to WASM); the same conformance cores; each service validated against its real
backend; Nano untouched. Backends already running: MinIO · fake-gcs-server · Azurite ·
Postgres · Vault · NATS-JetStream.

Status: IN PROGRESS · Target: v2.5.0 · Created 2026-07-13
