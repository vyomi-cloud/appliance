- **GCP:** `gcloud functions deploy --gen2` works without the `packaging` module (`core/gcp_function_runtime.py`, test `tests/test_function_requirements_no_packaging.py`).
- **Release checks:** SDK pass-rate step and marker (`scripts/release_checks_sdk_rate.py`); retired startup/MSI waits are skipped.
- **Tunnel:** vyomi-tunnel 1.3.1.
