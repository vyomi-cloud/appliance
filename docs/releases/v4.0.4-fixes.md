# v4.0.4 — fixes to the AI stack Beta

A fix release on top of v4.0.3. No new product surface; the AI stack stays a **Beta** and every feature stays **Dev Simplified**.

## Fixes
- **Nano relay (important):** the relay endpoint page lacked 14 AI cores that the relay shared worker loads (265 vs 279), so requests that reached the GCP AI router through the Nano tunnel returned HTTP 500, and four Azure Service Bus (AMQP) claims on Nano failed. Fixed, with a parity test that fails if the two lists drift again.
- **Notices:** Vault 1.15 is licensed BUSL-1.1, not MPL-2.0 as v4.0.3 listed. The notices, SBOM and the in-console Notices page are corrected and the Vault licence text ships in `licenses/`.
- **Mesh:** the `llm-chat` entry script now restarts llama-server without adapters when a LoRA adapter fails to load (verified in the real llama.cpp server image).
- **Mesh:** the Facilities agent reference app is available in the Mesh Codespace (`vyomi-agent-demo`, see `codespace/MESH-DEMO.md`). The Mesh simulator container now sets dummy `AWS_*` credentials so Lambda functions can call back into it with boto3.
- **Tunnel:** the Homebrew formula is brought to vyomi-tunnel 1.2.5.
- **Tests:** the capability check now runs pytest-style files and isolates state per claim; stale tests repaired (see `docs/architecture/v4.0/CAPABILITY-CHECK-ENV.md`).

## Docs
- `docs/architecture/v4.0/BACKEND-LICENCE-PLAN.md`: plan for the MinIO (AGPL) and Vault (BUSL) backends. Not implemented in this release.

Real-model numbers were measured on a Mac, not a Codespace. Licence text is an engineering draft and has not had legal review.
