# Vyomi v2.8.0 — VPC network-simulation data plane

**Goal:** close the last open parity data plane (PARITY P4 #15 remainder) with a real
VPC network simulation — not a catalog stub. The centerpiece is a **reachability
analyzer**: given a source + destination + port, evaluate the whole path (route table
→ security groups → network ACLs) and report **reachable / blocked and WHY**.

**Principles (unchanged):** additive; substrate-free core (Nano gains it too); proven
by a conformance test; never a false green.
