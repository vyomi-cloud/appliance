# Vyomi v2.7.0 — API Gateway data plane

**Goal:** close PARITY P4 #15's API-gateway remainder with a real, testable data
plane — not a catalog stub. A deployed REST API actually **routes an HTTP request
to a resource + method, executes its integration, and returns a response**. The
headline is the Lambda-proxy path: API Gateway → `lambda_core` sandboxed invoke →
HTTP response = a genuine serverless HTTP API entirely in-core.

**Principles (unchanged):** additive; substrate-free core (Nano gains it too);
proven by a conformance test; never a false green.
