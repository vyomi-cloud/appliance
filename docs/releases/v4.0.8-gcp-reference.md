# v4.0.8 — GCP reference architecture (13/13)

The 13-component agentic reference application now runs on **GCP** through the real, unmodified Google client libraries, the way the AWS one does (`run_e2e.py --cloud gcp`). This is a Beta, and every AI feature stays labelled **Dev Simplified**.

## What is new
- **GCP reference app:** `examples/enterprise-facilities-agent/facilities/gcp/` (13 components) with a cloud-neutral harness and `README-GCP.md`. The approval step is assembled from Pub/Sub, a Cloud Run function and a Firestore ledger (GCP has no Step Functions equivalent; the report says so).
- **Cloud Run functions:** Python functions run in a sandboxed subprocess and can call the simulator with the real Firestore, Pub/Sub, Storage and Secret Manager clients; stdout and stderr reach Cloud Logging.
- **Real backends (Mesh and offline only, opt-in):** `VYOMI_GCP_REAL_BACKENDS=1` makes the real Google Pub/Sub and Firestore emulators the data plane; the stock gRPC clients work, and a small gRPC front serves the Logging and Monitoring clients. Default behaviour and Nano are unchanged.
- **Identity:** an Identity Platform sign-in core issuing verifiable ID tokens; API Gateway accepts real OpenAPI specs and validates ID tokens, and forwards the real `X-Apigateway-Api-Userinfo` header.
- **Vertex AI:** Model Armor enforced on the model call and with integer enums; Agent Engine source-package hosting with SDK-valid responses; Sessions `events.append/list`; `models.get` for the served model ids; `generateContent` with a RAG retrieval tool returns grounding metadata.
- **Other GCP fixes:** Logging timestamp filters, Trace v1/v2 span ids, KMS additional authenticated data, GCS bucket notifications, event functions that `print`.
- **Reference app (all clouds):** `FACILITIES_READ_TIMEOUT` environment override for the SDK read timeout.

## Honest limits
- Measured on macOS arm64 with the in-process simulator and a CPU-served Qwen3-4B; not run on a Codespace or the real Mesh stack. Answer quality is that of a small model.
- Real-backend mode: Pub/Sub schemas, IAM and the console message peek do not apply to emulator data; only the default Firestore database is proxied; Firestore triggers do not fire for direct gRPC writes. Firestore is Max-tier on a licensed appliance.
- Cloud Armor policies are stored but not evaluated. Python functions only; a fresh process per call.
- The Azure reference app is not part of this release.
- Public claim wording comes from `docs/architecture/v4.0/AI-SELLABLE-CLAIMS.md`.
